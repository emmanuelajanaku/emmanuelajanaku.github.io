EMMANUEL AJANAKU — PORTFOLIO WEBSITE
=====================================

PACKAGE CONTENTS
- index.html: complete responsive portfolio website
- assets/emmanuel-portrait.png: professional portrait for homepage
- assets/emmanuel-laboratory.jpg: laboratory photograph for About section

DESIGN
Dark/black background, white typography, bright blue accents and buttons, responsive navigation and content cards, inspired by the visual direction in the reference screenshot while using Emmanuel's own content and photographs.

PUBLISHING / UPDATING GITHUB PAGES
1. Open https://github.com/emmanuelajanaku/emmanuelajanaku.github.io
2. Open the repository's main page.
3. Upload the new index.html file and the entire assets folder (including both images).
4. If GitHub asks whether to replace index.html, choose the option to replace it.
5. Commit the changes to the main branch.
6. Wait a few minutes, then refresh https://emmanuelajanaku.github.io

IMPORTANT BEFORE OR AFTER PUBLISHING
- Replace ADD-YOUR-EMAIL-HERE in index.html with your public professional email.
- Replace https://www.linkedin.com/ with your actual LinkedIn profile URL.
- The CV section currently invites contact; no CV PDF was included in the available files, so no fake download button has been added.
- Review all dates, titles and descriptions before using the site in formal applications.
- Do not publish private or sensitive personal information.
